## 一、对外发布版（面向用户升级说明）

### ETZ21 Pro Plus 固件更新说明

1. **新增五轴协同防抖支持与新一代机身防抖兼容优化**
   - 适配带光学防抖的索尼 E 卡口原厂及副厂镜头（OSS / VC / OS / OIS）：自动由镜头负责 Pitch / Yaw 光学防抖、尼康机身负责 X / Y / Roll 传感器防抖，大幅提升中长焦手持防抖效能与取景稳定性。
   - 支持尼康机身菜单 **防抖开 / 关 / Sport 运动模式** 与镜头实体防抖开关双向同步；**修复在尼康 `Z9 / Z8 / Zf / Z6III / Z50II` 等新一代机身上关闭菜单防抖后，镜头光学防抖仍常开的问题**。
   - 优化近摄/微距场景下的平移防抖补偿精度，支持待机/关机时防抖镜组自动归中锁止保护。

2. **对焦精度、暗光合焦表现、老款镜头兼容性与电动变焦全面升级**
   - **显著改善暗光环境合焦表现**：优化弱光及低反差场景下的反差微摆扫描与微步驱动控制，结合精准出瞳/渐晕通光参数传递，减少暗光拉风箱，大幅提升弱光环境合焦速度与成功率。
   - **新增收光圈焦点偏移（球差）与全画幅边缘相位对焦补偿**：支持自动读取并缓存索尼镜头内置光学瞳距/像差数据（同时内置 **57 款**早期索尼镜头光学参数库），大幅提升大光圈镜头收缩光圈实拍及边缘对焦点的合焦准度。
   - **修复索尼 `E 18-55mm F3.5-5.6 OSS`、`E PZ 16-50mm F3.5-5.6 OSS` 等早期原厂镜头的对焦微颤与拉风箱问题**，还原经典老镜头专属对焦灵敏度曲线。
   - **修复 `E PZ 16-50mm` 等电动变焦镜头上电或变焦后偶发卡死、无法对焦的问题**。
   - 补齐尼康全套两段式消隙定位、反差微摆与平滑制动指令，提升视频追焦与微距慢速对焦平顺度。

3. **重新加入待机低功耗模式（保持焦点）与休眠换镜自动识别**
   - **重新加入待机低功耗模式**：**索尼原生 E 卡口镜头（不包括转接环）及部分腾龙镜头**在相机待机时会进入低功耗休眠模式，**半按快门唤醒后保持休眠前的对焦焦点位置**；**其他镜头（含转接环）仍沿用原有策略，在待机/关机时完全切断电流**。
   - **新增待机休眠期间拆装/更换镜头自动识别**：低功耗休眠状态下拔下镜头、更换另一支自动镜头，或由手动镜头更换为电子镜头时，休眠中安静记录换镜状态且不误唤醒机身；待下次唤醒机身时自动触发断电重新识别新镜头参数。

4. **光圈显示校准与机内光学矫正（畸变 / 暗角 / 色差）增强**
   - 修复部分 `F1.2`、`F1.8` 等镜头在尼康机身上最大光圈显示偏差 `0.1` 档（如显示为 `F1.1`、`F1.3`、`F1.9`）的问题，确保机身光圈刻度、实体光圈环全开档与 EXIF 记录严格一致。
   - 修复变焦镜头在变焦过程中机内暗角、畸变与色差矫正系数未随焦距实时同步的问题，以及中长焦镜头（`>100mm`）在新一代机身上取景与成片边缘裁切不一致的问题。
   - 内置及新增以下 **8 款**镜头的尼康机内原生光学矫正数据（畸变 / 暗角 / 倍率色差）支持：
     - **索尼 `FE 16-35mm F4 ZA OSS (SEL1635Z)`**
     - **索尼 `FE 50mm F1.2 GM (SEL50F12GM)`**
     - **索尼 `FE 50mm F1.8 (SEL50F18F)`**
     - **索尼 `FE 85mm F1.4 GM (SEL85F14GM)`**
     - **索尼 `FE 70-200mm F2.8 GM OSS (SEL70200GM)`**
     - **索尼 `E 18-200mm F3.5-6.3 OSS (SEL18200)`**
     - **腾龙 `28-75mm F/2.8 Di III RXD (A036)`**
     - **腾龙 `70-300mm F/4.5-6.3 Di III RXD (A047)`**

5. **系统稳定性与通信可靠性增强**
   - 扩容新一代尼康机身高速通信缓冲区，修复极端快速连拍、频繁变焦或热插拔镜头时的潜在异常隐患。

> **【使用提示】**  
> **首次更换或安装新镜头时**，受机身与镜头上电初始化时序影响，当前镜头的部分识别参数或光学矫正/防抖配置可能尚未在首轮开机的瞬间完成切换。**首次换上新镜头开机识别后，请将相机关机并重新开机一次**，转接环即会自动记忆该镜头配置，后续正常开关机无需重复操作。

## 二、研发工程详细版（内部归档 / Git Commit）

### 2.1 `2026-11-24` 固件增量更新明细

#### 1. 重新加入待机低功耗模式（保持焦点）与双轨电源管理（`main.c`、`NikonzDriver.c`、`SonyEmountDriver.c`、`initial.c`）
- **分级待机策略（低功耗保焦点 vs 完全断电）**：
  - **索尼原生 E 口镜头（排除 `FunctionMode != 1` 转接环）与部分腾龙镜头**：进入待机时先维持 50Hz `VD` 脉冲发送 `B2L 0x0A -> 0x16` 等待镜头返回 `SleepReadyStatus == 0x00` 进入微安级休眠，再由 `ZmountCmd51()` 返回 `0x01` 通知尼康机身保留 `3.3V` 待机供电并让 STM32 进入 `STOP` 模式；**唤醒后镜头不掉电复位，直接保持休眠前的对焦焦点位置**。
  - **其他副厂镜头 / 转接环 / 手动镜**：沿用原有待机策略，`ZmountCmd51()` 返回 `0x41` 由尼康机身在待机/关机时**完全切断卡口供电电流**。
- **休眠态镜头失连 / 重连检测与延迟重枚举**：`STOP` 模式保持 `CAMERA_DET_CTRL = 1` 并启用 `PB7`（`EXTI_Line7` 双边沿）中断唤醒；检测到拔出失连或新接入电子镜头经消抖确认后，置位 `bitSleepLensChanged = 1`、关闭 `EXTI_Line7` 并将 `PB7` 切为 `AIN`（`0 µA` 静态电流）继续安静休眠；待下次机身 `Z_CLK` 唤醒时读取标志并拉低 `CAMERA_DET_CTRL = 0` 等待尼康机身断电重枚举。顺带修复 `SCK_EXTI5_Disable()` 误关共享 `EXTI9_5_IRQn` 的问题。

#### 3. 索尼 `Catalog 0x00 ("LF/ED")` 在线流式解析、57 款内置表与尼康 `C400 / L2B2000` 瞳距像差闭环
- 工作模式异步分包拉取 `0x3A / 0x3B` 解析 `LF / ED / CS` 数据块并持久化至 `0x0801DC00` Flash 缓存，叠加 57 款内置镜头表回退，双线性插值实时刷新 `L2B2000 (+0x11..+0x57)` 与 `CMD 0xC400 / C200 / C300` 收光圈焦点偏移补偿。

#### 4. Expeed 7 防抖常开修复、老款 E 口镜头拉风箱修复与 `16-50 PZ` 变焦死循环修复
- 识别 Expeed 7（`Z9 / Z8 / Zf / Z6III / Z50II`）`B2L2000` `0x1B` 防抖关闭码并扩充 SPI 缓冲至 `300 B`；修复前 `v1.30` 协议老镜头（`SEL1855 / SELP1650`）`GetCmd06Data()` `VD` 位置锚点超前 1 帧及 `SysTick` 跨 `VD` 原子快照问题；修复 `DispatchSonyFrame()` 丢弃 `FrameType=1` 非 `0x05` 帧导致的 `SELP1650` `0x1D` 死循环。
