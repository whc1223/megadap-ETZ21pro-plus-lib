### 2.1 `2026-11-26` 防抖控制子系统全链路重构与无跳变状态机优化（`NikonzDriver.c`、`SonyEmountDriver.c`、`NikonZmountProtocolDef.h/.c`、`SonyEmountProtocolDef.h`、`initial.c`）

> 当前编译镜像统计：`Code=53558, RO-data=36718, RW-data=1536, ZI-data=17336`；压缩加载区 `LR_IROM1` 结束于 **`0x0801C2E0`**，距离 `0x0801D800`（`LEN_INFO` 与 `Catalog 0x00` 持久化保留页）尚余 **`5,408 Bytes`**（`0 Error(s), 0 Warning(s)`）。

1. **尼康 Z 端权威镜头防抖指令对 `CMD 0xD200 / 0xD400` 与 `CMD 0xEF00` 完整接入（基于 Z9 `v1.11` 固件逆向）**：
   - **修正 `B2L 0x2000 +0x09` 历史误判**：逆向 Z9 `0x40C70030..0x40C70058 -> Build_B2L2000 @ 0x40E00944` 证实 `+0x09` 低 3 位并非机身 VR 档位标志，而是 `bit2 (0x04)` = 实时取景/测光常驻位（关防抖仍为 `1`）、`bit1 (0x02)` = **AF 对焦运行激活位**、`bit0 (0x01)` = **快门 S2 曝光激活位**；同时 Expeed 7 在菜单关防抖时 `B2L2000 +0x0D` 仍发 `0x1F`（仅 `target_x/y = 0`）。
   - **新增 `Handler_D200()` 并修正 `Handler_D400()`**：接入 2019+ 全系尼康 Z 机身权威防抖控制指令对：
     - `CMD 0xD200`（8B，`Req_Z_LensCmd_D200 @ 0x40DEB48C`）：`byte[1] & 0x0F` = `0x01`（Normal）、`0x04`（Sport）、`0x02`（Tripod）开启镜头 VR；
     - `CMD 0xD400`（4B，`Req_Z_LensCmd_D400 @ 0x40DEB8C0`）：菜单防抖设为 `OFF`、开机预初始化（`WorkFlowA`）或进入回放/菜单（`WorkFlowC`）时机身发 `flags = 0xE3`（`bit6=1, bit5=1`，**立即停止镜头 VR 并保持机械解锁**）；关机/休眠（`WorkFlowB`）发 `flags = 0xC3`（`bit6=1, bit5=0`，归中锁止并回报 `0x3E/0x02`）；未见过 `0xD200` 的 2018 初代固件自动回退至 `Handler_2000()` 目标非零检测。
   - **新增 `Handler_EF00()` 拍照/视频模式识别**：解析 3B `CMD 0xEF00`（`Send_Z_B2L_EF00 @ 0x40DFA378`：`0x02` = 照片模式，`0x03` = 视频模式），结合 `B2L2000 +0x02 bit3` 驱动照片按需防抖 vs 视频常开防抖。

2. **索尼 E 端物理防抖开关能力精准判别与防回显死锁保护（基于 `ILCE-7M4 cpapp-b.bin` 与 `SEL70200GM` 双端逆向）**：
   - 核实 `L2B 0x08 (+0x1B) LensAttrib02` 高半字节硬件能力声明：`bit4 (0x10)` = 镜身物理 `OSS ON/OFF` 开关支持位（实时状态在 `StatusA08 SwitchKey1 bit4`），`bit5 (0x20)` = 镜身物理 `OSS MODE 1/2/3` 开关支持位（实时状态在 `SwitchKey1 bit6:5`）。
   - 关闭防抖时：仅对具备物理 ON/OFF 开关且物理开关处于 ON 的镜头发送 `SteadyShotCtrlFlags = 0x42U`（`bit6=1` 机身覆盖关停），无物理开关镜头（如 `SELP1650 / SEL1855 / SELP16502`）发送纯净 `0x02U`；并仅在未置位 `bit6 (0x40)` 覆盖时采样锁存 `s_phys_oss_sw_on`，规避 `SEL70200GM sub_46E02` 将覆盖后的 `0` 回显至 `SwitchKey1 bit4` 引发的菜单死锁。
   - 运动模式接管：当机身菜单选 `Sport` 且镜头具备物理 `MODE` 开关（`LensAttrib02 & 0x20`）时，置位 **`0x84U`（`bit7=1 CameraOverride_ModeSwitch` + `Mode 2`）** 突破 `SEL70200GM sub_4720A` 门控；选 `Normal` 时保持 `bit7=0` 尊重镜筒物理 `MODE` 拨杆。

3. **照片模式半按启动、`ON / Sport` 曲线分化（消除慢移停手拉扯感）与同组零跳变过渡状态机**：
   - **按需触发与 `2.0s` 保持窗口（`NIKONZ_OSS_PHOTO_HOLD_VD = 100`）**：照片模式待机下 OSS 静默休眠；检测到 `NORMAL` 取景态下的 AF 驱动指令、`B2L2000 +0x09` 的 `AF(bit1)/S2(bit0)`、MF 手动对焦环转动或电动变焦时 `< 20 ms` 瞬时激活，`AF-C` 持续刷新、`AF-S` 保留 `2.0s` 构图窗口后平滑退回待机；视频模式全程常开。
   - **消除慢移停手拉扯感与跨组跳变（`SEL70200GM sub_1F3E0 / sub_222BE / sub_1FDEC / sub_2433E` 实证）**：
     - 保持 `SteadyShotParam_12 = 0x00U`（避免无 `B2L 0x24` 时触发 `unk_2000353C = 1` 外部坐标跳变），新增 `SonyEmount_CalcGravityParam11()` 将 `B2L2000` `(Gx, Gy)` 实时换算为 `1..4` 重力朝向补偿；
     - **`ON（标准）` 拍照模式（锁定在组 `0x10`）**：待机 `EventCode=0x02, Flags=0x03`（`state 17`）$\leftrightarrow$ 激活 `EventCode=0x03, Flags=0x03/0x01`（`state 18`，定点强稳像），组内线性渐变零跳动；
     - **`Sport（运动）` 拍照模式（锁定在组 `0x30`）**：待机保持 **`EventCode=0x07` 不变**、置 `bit0=0`（`0x06 / 0xC6` $\to$ `state 48` 陀螺静音待机）$\leftrightarrow$ 激活 `EventCode=0x07, bit0=1`（`state 49/50` 平顺运镜曲线，彻底消除慢移停手反向回拽感）；松手 2s 后由镜内 `sub_2433E` 按 $v_k = \frac{65382}{65536}\,v_{k-1}$（$\tau \approx 106\text{ ms}$）指数衰减丝滑归零，彻底消除按下与松手后的画面跳动。

    - 全画幅（14 组）：`0x805E SEL50F12GM`、`0x8037 SEL85F14GM`、`0x801C SEL85F18`、`0x803E/0x8130/0x8131 SEL70200GM (NoTC/1.4X/2.0X)`、`0x8074/0x813F/0x8140 SEL70200G2 (NoTC/1.4X/2.0X)`、`0x806E SEL2070G`、`0x802B SEL1635Z`、`0x802F SEL24240`、`0xC040 ZEISS Batis 2/25`、`0xC138 Tamron 70-300 A047`
